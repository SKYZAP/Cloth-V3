## Chat list
- Right-click a chat to rename it in place, move it to a project, archive it or delete it (delete asks inside the menu). The menu key, Shift+F10 and F2 work from the keyboard too.
- Drag chats to put them in your own order, or drop one on a project's heading to move it there. Esc cancels a drag, and Alt+↑/↓ moves the open chat. Right-click a heading and pick **Sort by date** to go back to newest first. New chats still start at the top.

## Chat header
- The header shows project / chat, and each part opens a switcher you can type in: pick another project or chat, see archived chats, or start a new one. **Ctrl+P** opens the chat switcher. Rename the chat from the ··· menu.

## Git
- The Git panel finds every repository in the chat's folder (its own, ones a folder or two down, and submodules) and lets you switch between them, with a count of changes on each. **All repositories** lists every repo's changes together. The choice is remembered per chat.

## Faster and steadier
- Changing the model or reasoning effort no longer freezes the chat while Cloth asks the provider about the model; the context meter updates when the answer arrives.
- **Jump to latest** no longer appears when there's nothing below.

## Also
- Attachments can be up to 100 MB (was 25 MB).
- OpenSpec changes and specs open in a reader: proposal, design, tasks and each spec change as tabs.
- Chats and the dashboard no longer list counts of failed commands and tools.
- If the newest release isn't ready to update from yet, Cloth updates from the newest one that is.
