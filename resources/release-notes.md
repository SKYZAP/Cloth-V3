## Updates
- Updates install without the setup wizard. A new version downloads in the background (only the parts that changed, where possible), then a message offers **Restart now**: Cloth closes, installs the update into the same folder and opens again by itself.
- If you don't restart, the update installs quietly the next time you quit Cloth.
- Updating to this version from 1.5.2 or older still shows the setup wizard once; updates after it are silent. macOS builds still update by downloading the new version from the Releases page.

## Sidebar
- The fold handle on the sidebar's edge no longer lights a red line or shows a tooltip, and it presses in when you click it.
