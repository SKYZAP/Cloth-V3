## Run
- Bonsai 2 now starts on Max reasoning (xhigh), and its Reasoning setting offers only the levels it supports: Low, Medium and Max.
- Existing Bonsai 2 runners set to Default switch to Max.

## Chat
- When a chat uses Bonsai 2, the effort picker shows only Low, Medium and Max.
- A chat set to a level Bonsai 2 doesn't take uses the next one up (High becomes Max), and so do agents that run on it.
