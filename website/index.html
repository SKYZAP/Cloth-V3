Cloth · Chat

Your code and keys stay on your machine.

Cloth is a desktop app first. The cloud is something you add, not something you need.

Run models on your GPU

Cloth installs and updates llama.cpp for you, suggests models that fit your graphics card, and lets you set context size and reasoning per model.

Connect any MCP server

Add servers by command or by address. The ones that need an account sign in through your browser, and you can change a server's permissions without restarting it.

Lend Cloth to your other tools

Cloth runs its own MCP server, so Claude Code, Cursor and Claude Desktop can search your knowledge and use your skills. One command connects them.

Secrets stay sealed

API keys, tokens and sign-ins are stored encrypted and never shown back in the app. Paired phones can chat, but they never see them.

 terminal
# Give Claude Code everything Cloth knows
$ claude mcp add --transport http cloth http://127.0.0.1:7811/mcp
Added HTTP MCP server cloth

$ claude mcp list
cloth: http://127.0.0.1:7811/mcp - ✓ Connected
$

Open source, every thread of it.

Cloth's code is on GitHub under the MIT licence. Read how it treats your keys, build it yourself, or send a fix.

  • Nothing hidden. Every request Cloth makes is in the code, and the installers are built from it by GitHub Actions.
  • Fork it. MIT means you can change it, ship it inside your own tools, and keep your changes.
  • Pull requests welcome. The test suite runs on every one, so you know before review whether it works.
